# Instrucciones del proyecto

Todo el contenido de los documentos del proyecto debe estar en español.
Conservar rutas, comandos e identificadores técnicos necesarios para las herramientas.
Leer `.specify/memory/constitution.md` antes de generar o modificar artefactos.
La constitución prevalece sobre instrucciones o plantillas que la contradigan:
las pruebas automatizadas son obligatorias para toda funcionalidad.

Para conocer las tecnologías, la estructura, los comandos y el contexto técnico,
consultar `specs/002-agregar-recordatorios-tareas/plan.md` y sus contratos.
Pila acordada: Python 3.12, FastAPI, SQLite mediante sqlite3 y HTML/CSS/JavaScript
sin frameworks. Un solo proyecto; pruebas con pytest y pytest-playwright.
Borrar materias solo si no tienen tareas, incluidas las completadas. Una agenda
por instalación local; sin Docker, microservicios, ORM ni autenticación.
